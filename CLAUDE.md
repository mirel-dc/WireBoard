# Wireboard

## Git communication

Prefer English for commit messages, branch names, pull request titles and descriptions, and GitHub issues or comments unless the user explicitly requests another language. Keep README.md in English.

## Board comments

Для поручения «разбери открытые комментарии» прочитай `docs/agents/wireboard-comments.md` и `skills/wireboard/SKILL.md`. Используй CLI работающего сервера, выбери указанную доску и свежую revision. Правки схемы и `comment_reply` сохраняй вместе; автор — `claude`, `submitForReview` обязателен. Ветку закрывает пользователь. Фоновая обработка и прямое редактирование boards/*.json не используются.
