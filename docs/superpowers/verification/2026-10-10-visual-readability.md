# Исправление читаемости Wireboard — 10 октября 2026

## Причина и направление

Новая оболочка редактора открывала сохранённую стартовую доску с прежним оформлением. Дополнительно renderer игнорировал fontSize подписи связи, рисовал её перед блоками и мог обрезать её при экспорте слайда. Размеры и внутренние отступы карточек оставляли слишком мало места для описания.

Пользователь уточнил направление тремя изображениями из LLM under hood: простые прямоугольные блоки, центрированный текст, мягкие цвета по роли, свободное место для подписей стрелок. Это уточнение уже разрешённой доработки визуала C.

## Изменения

- Новая карточка 220×112, padding 16; заголовок при fontSize 16 имеет размер 20. Текст прямоугольника центрируется по обеим осям, сохраняются переносы, clipping и индикатор переполнения.
- Радиус угла блока 5, рамка 2. Пресеты: голубой, жёлтый, мятный и сиреневый.
- Подпись связи использует сохранённые fontSize/fontWeight, до двух строк; ищет свободную позицию рядом с маршрутом с учётом блоков и содержащего слайда. Общий экспорт учитывает размеры подписей. Белая подложка без отдельной рамки.
- Свежая стартовая схема: слайд 960×540, блоки 200×96, промежутки 148. Сохранённые доски автоматически не мигрируют.
- Инструкция skills/wireboard/SKILL.md содержит рекомендации по цвету, размерам, размещению подписей и проверке render для следующих сессий Codex/Claude.
