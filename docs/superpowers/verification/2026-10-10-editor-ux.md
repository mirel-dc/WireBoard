## Delivered behavior

Board v3 stores explicit frame membership. Resize changes frame bounds only; children retain size and membership, including those now outside the bounds. Eight 24 CSS-pixel handles support independent edges, opposite-corner preservation and Shift aspect lock. Free frame default, 960×540 slide preset, fit-to-content, header/border movement and interior marquee are available. Intentional drop updates membership atomically with movement; one Undo reverses both.

User history uses field deltas and stamps rather than whole-board snapshots. Independent agent text survives own Undo; same-property and ABA changes conflict. Browser command queue keeps rapid gestures and early Undo, handles own SSE before ACK, and verifies receipts before repeating uncertain commands. Board/history/stamps/receipts commit in one atomic envelope and survive restart; exports remain portable Board JSON.

Gesture conflict baselines are captured on pointerdown. Property edits capture a focus baseline and patch only the edited dimension. Truncated successful responses remain uncertain. Late text acknowledgements reconcile their original draft, preserving replacement drafts and text typed after Save.

Preview and Rust SVG/PNG render use the same font advance metrics, wrapping, clipping and connector caption placement. Existing pastel visual direction and comments workflow remain in place.
